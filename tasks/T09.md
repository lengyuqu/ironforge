### 2. Outline 模型

新建 `crates/rg-core/src/search/outline.rs`（或 `search/outline/` 子模块，若超过 600 行）：

```rust
pub enum Language { Rust, TypeScript, Tsx, Python, Go, Svelte }

pub enum ItemKind { Function, Method, Struct, Enum, Trait, Impl, Class, Interface, Module, Const, Macro, Type, Other }

pub struct OutlineItem {
    pub name: String,
    pub kind: ItemKind,
    pub start_line: u32,      // 1-based
    pub end_line: u32,
    pub signature: String,    // 首行，截断到合理长度，去缩进
    pub exported: bool,       // Rust: pub；TS: export；Python: 不以 _ 开头；Go: 首字母大写
    pub children: Vec<OutlineItem>,
}

pub struct Outline {
    pub language: Language,
    pub items: Vec<OutlineItem>,
    pub truncated: bool,       // 命中上限时 true
    pub error: Option<String>, // 解析失败的原因，fail-soft
}
```

`extract_outline(path: &str, source: &str) -> Outline`：按扩展名判语言，未知语言返回 `Language` 缺省 + 空 items + `error: Some("unsupported language")`。

### 3. 质量要求（决定这个任务有没有价值）

- **必须是结构化抽取，不是正则**：用 tree-sitter 查 query，拿到真实的节点层级（`impl` 含方法、`class` 含方法、`trait` 含签名）。
- **fail-soft**：语法错误的文件（半截代码、二进制混入）返回 `error` + 空/部分 items，**绝不 panic、绝不返回 Err 让调用方崩**。
- **性能上限**：单文件 > 512 KiB 直接跳过（`error: Some("file too large")`）；单文件 item 数上限 2000（`truncated: true`）。理由写进 plan。
- **不含内容**：`signature` 只放首行，**不要把函数体塞进去**（这是 token 预算的前提，后面 T10 要靠它裁剪）。
