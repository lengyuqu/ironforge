## 要求

### 1. 端点契约

`GET /ai/repos/{owner}/{name}/map?ref=<branch>&budget=<tokens>&path=<subdir>`

| 参数 | 必填 | 说明 |
|---|---|---|
| `ref` | 否 | 分支/标签，缺省用默认分支；**必须走现有的 ref 解析与权限校验**，不要自己拼路径 |
| `budget` | 否 | token 预算，默认 4000，上限 32000；非法值 400 `INVALID_BUDGET` |
| `path` | 否 | 只映射某个子目录 |

响应形状（示意，字段名可微调但语义必须齐全）：

```jsonc
{
  "ref": "main", "commit_sha": "…",
  "budget": 4000, "estimated_tokens": 3120, "truncated": false,
  "directories": [
    { "path": "crates/rg-core/src", "files": 42, "languages": ["Rust"] }
  ],
  "files": [
    { "path": "crates/rg-core/src/search/outline/mod.rs", "language": "Rust",
      "items": [ { "name": "extract_outline", "kind": "function", "start_line": 88,
                   "end_line": 140, "signature": "pub fn extract_outline(path: &str, source: &str) -> Outline", "exported": true } ] }
  ],
  "skipped": [ { "path": "big.bin", "reason": "unsupported language" } ]
}
```

### 2. 预算裁剪（这是本任务的核心，别做成"列全部再截断"）

目标：**给定 budget，产出最有信息量的结构视图**。必须实现真正的裁剪策略：

1. **只考虑源码文件**：按扩展名过滤（`.rs/.ts/.tsx/.py/.go/.svelte`），非源码文件进 `skipped`（reason `unsupported language`），不占预算。
2. **目录聚合优先**：先按目录汇总（文件数、语言分布），目录层本身几乎不占预算。
3. **文件排序**：按「导出项数量 × 类型重要度」降序（`Struct`/`Class`/`Trait`/`Interface` 权重高于 `Function`，`Method` 依附于父项），保证预算先花在最能表达结构的文件上。
4. **截断顺序**：预算不够时，先丢弃低权重文件的 items（文件本身保留在 `files` 里但 `items: []` 并标 `"items_omitted": true`），再整文件移入 `skipped`（reason `budget`）。**不要**把某个 item 的 signature 从中间切断。
5. **`estimated_tokens` 估算口径要写进 plan**（建议 `字符数 / 4` 向上取整，中英混排时说明误差），并且**必须自检**：`estimated_tokens <= budget`，超出则继续裁剪（不能只估一次）。
6. **`truncated: true`** 当且仅当有内容因预算被丢弃。

### 3. 规模与性能保护

- 单次请求最多解析 **2000 个文件**，超出部分进 `skipped`（reason `too many files`）。
- 单文件上限沿用 T09 的 `MAX_FILE_BYTES`（512 KiB）。
- 并发解析要有上限（不要 `join_all` 打满；建议 `buffer_unordered(8)` 或等价）。
- 大仓库要能跑完：如果你的实现对 2000 个文件耗时超过 3 秒，在 plan 里报告实际数字，不要隐藏。

### 4. 权限与一致性

- 用与其它 AI 端点**相同的**鉴权路径（`ai_repo_tree` 怎么校验就怎么校验），不要自造。
- 私有仓库未授权访问要 404 或 403（与现有行为一致，不要泄露存在性）。
- `ref` 不存在 → 404 `REF_NOT_FOUND`。
- 审计：只读端点，**不写审计**（与 `ai_repo_tree` 一致）。

### 5. 契约三处同时补齐

`lib.rs` 路由 + `openapi.rs` 条目 + `route_meta.rs` 的 `repo(...)`。缺一个契约测试就会失败——那不是 bug，是设计。
