# Task T26 - [#41·R11] CI 容器默认以调用进程的 UID 运行

> 本文件是该任务状态的唯一权威；`TASKS.md` 只放镜像索引。

## Task Constraint

#41 的核心未解项：

> 工作区 rw 挂载 + 容器内 root 仍能在宿主留下 root 属主文件

`rg-ci-isolation` 的其它加固都做了（`--cap-drop ALL` 后只回 5 个、`no-new-privileges`、内存/CPU/pids 限额）。缺的就是「容器内进程是谁」。

## 决策（已定）

**`DockerLimits::user` 默认改为「IronForge 进程自己的 `uid:gid`」**，不是固定的 `1000:1000`。

理由：
- workspace 目录由 IronForge 进程创建，**属主天然匹配**，不需要 `chown`、不需要 `chmod 777`
- 容器内写出的文件属主 = IronForge 的 UID，宿主上不再是 root
- 固定 `1000:1000` 与宿主用户不匹配，反而要额外 chown，且 chown 需要 root 权限（IronForge 未必有）

**daemon 级 `userns-remap` 不在本任务范围**（那是部署层配置，且影响整个 daemon）。

## 已核实（`876706a` 基线）

- `DockerLimits`（`rg-ci-isolation/src/lib.rs:44`）已有 `user: Option<String>` 字段，注释写着 "None leaves the image default (usually root)"。
- `hardening_args()` 已经会传 `--user`（`:106`）。
- `Default`（`:63-76`）里 `user: None`。
- 三个使用点全用 `Default`：
  - `rg-ci/src/runner.rs:58`、`:78`（`docker_limits: DockerLimits::default()`），`:682` 调 `hardening_args()`
  - `rg-cli/src/main.rs:2643`
  - `rg-runner/src/main.rs:598`、`:667`
- 所以**只改 `Default` 就全局生效**，无需改这三处调用点。

## 要求

### 1. `Default::user` = 当前进程 UID:GID

- 取 UID/GID：优先用现有依赖（先查 `Cargo.toml` 里有没有 `libc` / `nix`；**没有的话用 `std::process::Command::new("id")` 解析**，或加 `libc` 依赖——**加依赖要在 plan 里说明理由**）。
- 格式：`"{uid}:{gid}"`（Docker 接受数字形式，不依赖容器内有同名用户）。
- **不要**设成 `1000:1000`。

### 2. 可回退（必须有）

有些镜像的 `run:` 阶段确实需要 root（比如 entrypoint 里 `apt-get install`、写 `/usr/local`）。提供环境变量：

```
IRONFORGE_CI_RUNNER_USER    # 默认空 = 用当前进程 uid:gid
                            # "root" 或 "0" = 显式回退到 root（即 user=None）
                            # 其它值 = 原样传给 --user（例如 "1000:1000"）
```

在 `DockerLimits::default()` 里读它。**读环境变量的地方只此一处**，不要在三个调用点各读一次。

### 3. 启动时警告（默认 root 时）

如果最终 `user` 是 `None`（用户显式回退），**在第一次构造 `DockerLimits` 时 `tracing::warn!` 一次**（不要每次 run 都刷），内容说明：「CI 容器以镜像默认用户（通常 root）运行，工作区挂载会让宿主产生 root 属主文件」。用 `std::sync::Once` 保证只警告一次。

### 4. 文档

在 `CLAUDE.md` 的「CI 容器隔离」相关段落（先找到现有段落，不要新开章节）补一句：默认 `--user <当前进程 uid:gid>`，需要 root 用 `IRONFORGE_CI_RUNNER_USER=root` 回退。

**注意**：`CLAUDE.md` 是本任务的例外允许项（只为了这一句）。
